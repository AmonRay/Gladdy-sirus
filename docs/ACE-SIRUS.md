# Общие Ace3 и совместимость ElvUI — Gladdy 2.42

## Решение

2.42 отменяет приватный UI-stack из 2.41. Регистраций библиотек с суффиксом `-Gladdy`, дополнительных префиксов фреймов/шрифтов, приватных media lists и собственных CreateFrame/CreateFont wrappers больше нет. Gladdy обращается к общим `AceGUI-3.0`, `AceConfig-3.0`, Registry/Cmd/Dialog, dropdown ItemBase и SharedMediaWidgets через LibStub.

Повторная загрузка встроенного файла проверяет регистрацию через LibStub. AceGUI registry, pool, counters и стандартные callback handlers переиспользуются, а не создаются отдельно для Gladdy. Общий pool проверен идентичностью Lua-таблиц и повторным получением того же объекта другим потребителем. Числовые замеры экономии памяти в клиенте не выполнялись.

Существующий собственный AceConfig ElvUI с суффиксом `-ElvUI` принадлежит ElvUI и не переименовывается: его использует сам ElvUI. Gladdy не создаёт дополнительный форк. Оба обращаются к одному общему AceGUI.

## Подтверждённая несовместимость RefreshTree

В предоставленном ElvUI функция `S:Ace3_RefreshTree(scrollToSelection)` вызывает `self.old_RefreshTree(self, scrollToSelection)`. Второй аргумент AceGUI `fromOnUpdate` теряется. Между тем TreeGroup из обоих Sirus-источников передаёт `true` из FirstFrameUpdate, чтобы завершить отложенную отрисовку. Без него виджет с родителем UIParent вновь назначает FirstFrameUpdate и выходит до отрисовки кнопок.

Автономный тест сначала воспроизводит повторное назначение OnUpdate на неизменённом TreeGroup ElvUI, затем проверяет исправленный общий виджет с той же исходной функцией-обёрткой. Исправление: FirstFrameUpdate временно отмечает выполнение на самом виджете, RefreshTree учитывает этот флаг даже при потере аргумента. Нормальное отложенное обновление не отключается, обёртка и скин ElvUI не заменяются.

Это подтверждённый дефект взаимодействия, но точная цепочка всех визуальных артефактов присланного скриншота без клиента не доказана. Успех автономного теста не объявляется скриншотной приёмкой.

## Источники и локальные адаптации

Исходники выбираются из предоставленных Sirus-репозиториев, а не по сравнению major/minor разных форков:

- ElvUI-for-Sirus: `1d4777f18c9fe10dcd031df0f77d0df962652fce`.
- WeakAuras-Sirus.su: `4196a715887f46316a773ff848e77dd7c2bb38b9`.
- FrameXML Sirus: `1c4353a3c3144f985b90494f357b198458a9995c`, `Interface/FrameXML/OptionsFrameTemplates.xml` и `.lua`: OptionsListButtonTemplate, именованный `$parentText`, шаг строки 18.

| Компонент | Источник | Изменения |
| --- | --- | --- |
| LibStub, CallbackHandler, AceDB, AceDBOptions, AceHook, AceSerializer, AceTimer | ElvUI | Сохранён комплект обновления 2.41, общие регистрации |
| AceComm / ChatThrottleLib | WeakAuras | Общие регистрации, совместимый wire protocol |
| AceGUI core | ElvUI | Общий core 10041; его исполняемый код совпадает с core WA 42, различаются регистрационный minor и комментарий. Не создаётся конкурирующее ядро другого форка |
| AceGUI widgets | WeakAuras | Общие типы; TreeGroup исправлен для RefreshTree-обёртки ElvUI; канонический именованный Text имеет приоритет с fallback к Text/text |
| AceConfig / Registry / Cmd / Dialog | WeakAuras | Исходные общие регистрации, без приватизации |
| AceGUI SharedMediaWidgets | WeakAuras | Общая регистрация и media lists; SetList при OnAcquire обеспечивает безопасный release пустого виджета |

TreeGroup получает версию 51 вместо upstream 50, а пять изменённых media widgets — следующий номер версии относительно источника: это регистрация реально изменённых общих конструкторов, чтобы исправление работало при любом порядке загрузки и не заменялось неизменёнными исходниками. Это не критерий выбора более нового источника и не новая библиотека. Устаревший объект TreeGroup в общем pool отбрасывается штатным version check AceGUI.

Точные источники и SHA-256 оригиналов/установленных файлов: [ace-sources.json](ace-sources.json). Лицензии и авторская документация сохранены. Новых нарративных комментариев в код не добавлено.

## Проверки

- 37 прежних регрессий Gladdy и 9 реальных библиотечных тестов, включая старый zlib-профиль.
- 8 Ace core тестов: существующие SavedVariables, copy/switch/reset профиля, AceDBOptions, сериализация с nil/бинарными данными, Hook/Unhook, version-check и multipart AceComm.
- 13 UI-сценариев при загрузке ElvUI core/TreeGroup до Gladdy и 12 при загрузке после: один экземпляр библиотеки, один registry/pool, повторное использование объекта разными потребителями, обновление старого pooled TreeGroup, отсутствие приватных библиотек/wrappers, общий счётчик имён и канонический Text, 25 default/media widgets, shared insert-link callbacks и media lists, AceConfig open/close и реальный ExportImport.lua.
- Исходная функция RefreshTree-скина ElvUI тестируется с выключенным и включённым ace3Enable. Неисправленный оригинал воспроизводит повторный OnUpdate, исправленный завершает отрисовку и снимает обработчик.
- Lua 5.1 syntax, TOC/XML dependencies, пофайловый provenance manifest и прежние operation-count benchmarks.

Фикстуры core/TreeGroup и функция RefreshTree взяты из указанного ElvUI без изменения логики; нормализованы LF и концевые пробелы. Для функции-фикстуры в манифесте указан исходный файл и выделенный диапазон функции. Это не запуск полного ElvUI: WoW API, сетевая доставка и остальные skin helpers имитируются. Клиентских замеров FPS/памяти нет.

## Приёмка в Sirus

1. Полностью заменить папку Gladdy версией 2.42, сохранить резервную копию WTF и выполнить `/reload`. Иначе в уже запущенном Lua-сеансе сохранятся регистрации предыдущей 2.41.
2. Без ElvUI/WA проверить `/gladdy`, выбор media, импорт/экспорт и старый профиль GladdyXZ. Настройки не удалять.
3. С ElvUI открыть `/ec` до `/gladdy`, затем наоборот. Проверить дерево, прокрутку, раскрытие групп, повторное открытие и отсутствие Lua errors.
4. Повторить с WeakAuras, загрузкой его настроек и после `/reload`. Проверить ace3 skin включённым и выключенным.
5. Проверить арену и version-check в группе. При оставшихся артефактах приложить Lua error, скриншот и версии ElvUI/WA.

Клиентская визуальная проверка пока не выполнена: клиента Sirus в рабочем окружении нет.
