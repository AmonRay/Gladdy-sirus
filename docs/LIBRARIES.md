# Библиотеки Gladdy 2.40

## Источники

- Gladdy: исходное состояние аудита — `bf981e2a7cec57de5ffc32459728f2335a06bb37`, версия 2.39.
- [ElvUI-for-Sirus](https://github.com/AmonRay/ElvUI-for-Sirus/tree/1d4777f): отдельный аддон, источник только совместимых библиотек и примеров Sirus API.
- [WeakAuras-Sirus.su](https://github.com/Accidev-Addons/WeakAuras-Sirus.su/tree/4196a715887f46316a773ff848e77dd7c2bb38b9): отдельный аддон, источник совместимых библиотек.
- [sirus-patch-ruRU-i](https://github.com/AmonRay/sirus-patch-ruRU-i/tree/1c4353a3c3144f985b90494f357b198458a9995c): FrameXML клиента, не исходники Gladdy.

## Решения

| Библиотека | Было | Решение | Основание и проверка |
| --- | --- | --- | --- |
| AceTimer-3.0 | 1018 | 1020 из `ElvUI_Libraries/Core/Ace3/AceTimer-3.0/AceTimer-3.0.lua` | Совместимый OnUpdate-драйвер без C_Timer; скрывается при отсутствии таймеров, учитывает ближайший срок, безопасно обрабатывает изменение списка внутри callback. Проверены аргументы с nil, отмена, repeating, создание в callback, upgrade активного handle. Только LF/концевые пробелы нормализованы. |
| CallbackHandler-1.0 | 7 | 8 из `WeakAuras/Libs/CallbackHandler-1.0/CallbackHandler-1.0.lua` | Сохранён API New/Register/Unregister/Fire. Проверены аргументы и регистрация callback во время dispatch. Авторский исходник сохранён. |
| LibDeflate | 1.0.1-release | 1.0.2-release, minor 3 из `WeakAuras/Libs/LibDeflate/LibDeflate.lua` | Числовая регистрация версии; zlib/print API совместимы. Round-trip, legacy-фикстура, отказ на повреждённых данных. Локально дополнительно проверен обмен с прежней 1.0.1 и Python zlib. Приложена исходная zlib-лицензия. |
| AceComm-3.0 / ChatThrottleLib | 13 / 25 | Сохранены | В WeakAuras 14/31, но меняется очередь отправки и callback отправки. Сетевой транспорт и смешанные версии требуют отдельного стенда/клиента; для текущего GladdyVCheck обновление не необходимо. |
| LibCustomGlow-1.0 | 16 | Сохранена | В ElvUI/WeakAuras 27, но меняются пулы/шаблоны и набор текстур, включая дополнительные крупные ресурсы. Gladdy использует PixelGlow_Start/Stop; доказанной необходимости расширять API нет. Не добавлялась зависимость от WeakAuras. |
| LibSpellRange-1.0 | 20 | Сохранена | В предоставленном WeakAuras 19: слепое копирование было бы downgrade. |
| LibSharedMedia-3.0 | 3030003 | Сохранена | В WeakAuras 3030002, в ElvUI 3040003 (другая ветка). Нет подтверждённого дефекта, требующего замены; сохранены существующие media/profile имена. |
| DRList-1.0 | minor 50, wotlk | Сохранена | Клиентские UI-репозитории не подтверждают актуальные серверные категории/длительности DR. |
| LibClassAuras-1.0 | minor 2, локальная адаптация | Сохранена | Таблицы привязаны к текущим настройкам отслеживаемых заклинаний; generic Retail-версия не подходит. |
| Остальные Ace3, LibStub, SharedMediaWidgets | Из базового Gladdy | Сохранены | Нет подтверждённой необходимости менять API всей UI/профильной инфраструктуры. |

Числа minor разных форков не являются универсальной оценкой качества. LibStub выбирает старшую зарегистрированную версию; при совместной загрузке ElvUI/WeakAuras фактический экземпляр может отличаться от встроенного в Gladdy. Нужна проверка обоих порядков загрузки.

Авторские лицензии и документация vendored-библиотек сохранены. Нарративные комментарии удалены только из собственного Lua-кода Gladdy и автономных тестов; исходники сторонних библиотек не переоформлялись под стиль проекта.
