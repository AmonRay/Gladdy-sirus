# Правила работы с репозиторием

- Рабочая целевая ветка — `main`.
- Повышать версию аддона только по прямой просьбе владельца. Обычное исправление, PR, merge или просьба продолжить работу не являются разрешением повысить версию. Без такой просьбы не менять `## Version` в `Gladdy/Gladdy.toc` и `version_major_num` / `version_minor_num` в `Gladdy/Gladdy.lua`.
- При явно запрошенном повышении версии согласованно обновлять `.toc` и числовую версию ядра. Релиз публикуется автоматически после изменения версии `.toc` в `main`; workflow сам версию не меняет.
- Не добавлять GitHub CI для синтаксиса, тестов, линтеров или benchmark. Единственный workflow — публикация релиза. Регрессионные тесты сохранять и запускать локально перед изменением кода.
- Переиспользовать общие библиотеки через LibStub из предоставленных Sirus-форков ElvUI/WeakAuras. Не создавать приватные `-Gladdy` регистрации, pools или префиксы фреймов ради изоляции.
- Не добавлять нарративные комментарии в собственный код. Сохранять лицензии и документацию сторонних библиотек.
- Потеря видимости игрока на арене не является завершением матча: сохранять фрейм, GUID и работающие кулдауны. Автоматически очищать состояние при нашем выходе с арены.
