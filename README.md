# Gladdy для Sirus DF UI

Gladdy - аддон арена-фреймов, который помогает следить за соперниками в PvP. Он собирает важную информацию о противниках в одном месте: здоровье и ресурсы, используемые способности и их кулдауны, эффекты контроля, усиления и ослабления. Гибкие настройки расположения, внешнего вида и профилей позволяют настроить интерфейс под свой стиль игры и быстрее принимать решения на арене.

> [!IMPORTANT]
> ### Только Sirus + DF UI
>
> Эта версия Gladdy предназначена **ИСКЛЮЧИТЕЛЬНО для клиента Sirus с DF UI**.
>
> **DF UI является обязательным условием работы этой версии.**
>
> Обычный клиент Sirus **без DF UI не поддерживается**. Поддержка других серверов, Classic и других вариантов интерфейса не заявляется.

## Возможности

- Здоровье, ресурсы, класс и определяемая специализация соперников.
- Классовые кулдауны, PvP-тринкеты и активные способности созвездий Sirus.
- Эффекты контроля, убывающая эффективность контроля (DR), усиления, ослабления, касты и прерывания.
- Питомцы противников, индикация дистанции, боя, текущей цели и фокуса.
- Настраиваемые объявления о важных событиях и таймер сумеречного зрения.
- Действия по клику: выбор цели, фокус, заклинание или макрос.
- Отдельные настройки модулей, размеров, шрифтов, цветов и расположения элементов.
- Профили с импортом и экспортом, русский и английский языки интерфейса.

Неизвестные противники не отображаются пустыми фреймами. После обнаружения соперника его фрейм и история кулдаунов сохраняются при невидимости. Автоматическая очистка состояния выполняется при выходе с арены.

ElvUI и WeakAuras не обязательны для работы. Общие библиотеки переиспользуются через LibStub, без отдельных приватных копий в памяти для Gladdy.

## Установка

1. Скачайте архив репозитория или опубликованный релиз.
2. Скопируйте папку `Gladdy` в `World of Warcraft/Interface/AddOns/` вашего клиента **Sirus DF UI**.
3. Проверьте путь: `Interface/AddOns/Gladdy/Gladdy.toc`. Дополнительной вложенной папки `Gladdy` быть не должно.
4. Перезапустите клиент или выполните `/reload`.
5. Откройте настройки командой `/gladdy ui`.

Профили сохраняются в `GladdyXZ`. Перед обновлением рекомендуется сделать резервную копию папки `WTF`.

## Команды

| Команда | Действие |
| --- | --- |
| `/gladdy` | Показать список команд |
| `/gladdy ui` | Открыть настройки |
| `/gladdy test` | Показать тестовые фреймы |
| `/gladdy test 1` … `/gladdy test 5` | Выбрать количество тестовых фреймов |
| `/gladdy hide` | Скрыть фреймы и сбросить их состояние |
| `/gladdy reset` | Сбросить текущий профиль |

Тестовый режим не отправляет групповые объявления товарищам. Команды скрытия и сброса очищают текущее состояние: не используйте их для обычного закрытия окна настроек во время матча.
